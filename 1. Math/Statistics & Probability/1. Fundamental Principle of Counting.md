The fundamental principle of counting is a core concept which is used to find the total number of possible outcomes when multiple actions or events are combined.

Case 1,

If we have 5 red balls and 3 blue balls , In how many possible ways can we pick one ball ?.
- Here there is 5 possible ways to pick a red ball and 3 possible ways to pick a blue ball. But question does not specify the color of the ball its is just asking us to pick any ball. Hence we can pick either red **OR** blue ball.
- Hence total number of possible way to pick 1 ball is : 5 + 3 = 7 ways

Case 2,

If we have 3 shirts and 2 pants, How many ways can we dress up?
- Here we can't choose either one and not other. We need combination of both to form 1 dress up. Now we have to choose 1 shirt then 1 pant. We have 3 ways to choose shirt and for each shirt there is 2 choices of pant. Hence we have to choose one shirt **AND** one pant.
- Hence total number of possible ways to dress up : 3 shirt * 2 pants = 6 ways.

>[! Note]
>Hence we have 2 fundamental rules for principle of counting :
>	1. Addition Rule (OR)
>	2. Multiplication Rule (AND)

## Event

A specific set or combination of outcomes we are interested in an experiment. An experiment can be any action that we do, for ex :
	1. Tossing a coins : possible outcomes are head or tail. This getting of head or tail is called event.
	2. Rolling a 6 sided die : outcome --> 6 (event).
### Mutually Exclusive Event

- If two event can't occur at same, it is called mutually exclusive event.
- Example 1 : Tossing a coin - here head and tail cannot occur at the same time. So the event of coming head and event of coming tail are mutually exclusive to each other.
- Example 2 : Non mutually exclusive event - if we roll a die and want an event where the number should be less than 3 and another event where number should be even. Here if we roll 2 both event are correct. Hence both event happened at the same time. 

### Mutually Independent Event

- If occurring of one event does not impact other it is called mutually independent event.
- Example 1 : Tossing a coin. If we toss a coin a get some outcome. Then toss again, the outcome that we got on previous toss has no impact of what we will get this time. Hence each toss is independent of previous outcome. 
- Example 2 : Picking a king from a deck of card and picking another king from same deck of card is not mutually independent event.  As when we picked one king from the card now the card has 1 less king so picking king again has lower chances.

## Addition Rule 

If a task can be done in one of several mutually exclusive ways, then total no. of ways is sum of each ways.

Example : I have 2 cars, 2 bike, 1 scotty.  No. of ways to go to office ?

## Multiplication Rule 

If a task consists of multiple independent subtasks then the total no. of ways is the product of ways of each subtask can be performed

Example : 3 pair of shoes, 4 pairs of socks. No. of ways to wear shoes?
