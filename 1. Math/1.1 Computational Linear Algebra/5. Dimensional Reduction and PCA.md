Reducing dimension basically mean reducing the number of columns in dataset. In machine learning the columns are the weights. If a dataset has many columns the matrix formed is very large so the computational cost is very high. Hence reducing no. of columns is required.

## How to reduce no. of columns

One way is to simply delete a few number of columns to decrease no. of columns but if we do so we are losing a lot of information which could prove crucial when training a model. Hence we must decrease the no. of columns as well as preserve as much information as possible from the deleted columns. 

![](dimensional%20reduction.png)

This is done by projecting two datapoints on a single line and getting a single datapoint on the line.

## Projections

![](projection.png)

We take an example dataset and plot it in x-y plane now we take a line $y=x$ onto which we are projecting the points. We treat each datapoint as a vector (ex : $a_{1}=\begin{bmatrix}1\\1\end{bmatrix},a_{2}=\begin{bmatrix}1.2\\1.8\end{bmatrix},a_{3}=\begin{bmatrix}-0.5\\0.2\end{bmatrix}\dots$) which we are projecting on another vector which forms $y=x$.   
We know projection of one vector on another can simply be calculated with dot product. But dot product between vectors $\vec{a}.\vec{b}$ gives us scalar multiple of projection of $\vec{a}$ on $\vec{b}$ and magnitude of $\vec{b}$. But we only need scalar projection of $\vec{a}$ on $\vec{b}$.
$$
\begin{align}
\text{Scalar Projection of }\vec{a} \text{ on } \vec{b}, \\
\frac{\vec{a}.\vec{b}}{||b||_{2}}
\end{align}
$$
The unit vector of $y=x$ is $\frac{1+1}{\sqrt{ 2 }}$ . Here we represented the datapoints as matrix 
>[!Note]
>Projection of matrix A on vector v is,
>$$
>	A.\frac{\vec{v}}{||v||_{2}}
>$$

![](reduced%20dimension.png)

Hence we have reduced dataset from two dimension to 1 dimension. 
>[!Note]
>The reduction necessarily does not  have to come down to 1D we can reduce 7D or 8D to maybe 4D or 5D. Here instead of matrix dot vector it will be matrix dot matrix. Where second matrix represent the line on which we are reducing the dataset to
>$$
>\begin{align}
>	A_{p}&=A.V \\
>	\text{dimensions,} \\
>	A_{p}=rX2 \\
>	A=rXc \\
>	V=cX2 \\
>	&\text{Here a dataset having r rows and c columns has been reduced to r rows and 2 columns, as we multiplied the dataset matrix A(rXc) with dimension reduction matrix V(cX2).}
>\end{align}
>$$

## Preserving Information

Projecting same dataset in different vectors.

![](multiple%20reductions.svg)

Here the same dataset is projected on multiple different lines. Now as we want as much information as possible to survive we take the projection where dataset are spread the most

![](spreads.svg)

### Variance

Now how to find the spread ? One way is to use the concept of variance from statistics.
$$
	\begin{align}
	Variance(X) &= \frac{1}{n-1}\sum_{i=1}^n(x_{i}-\mu_{x})^2 \\
	Variance(Y) &= \frac{1}{n-1}\sum_{i=1}^n(y_{i}-\mu_{y})^2 \\
	\text{Here, } \\
	n&=\text{number of datapoints} \\
	\mu &= mean 
	\end{align}
$$
Even though the variance help us show spread it cannot different between dataset that are mirror of each other.

![](variance%20issue.svg)

Here variance of both dataset will be same but clearly both dataset are not same as one has downward trend (y decreases as x increases) and other has upward trend (y increasing as x increases).

### Covariance

Covariance help us find spread as well as preserve the trend.

$$
	\begin{align}
	Cov(x,y) = \frac{1}{n-1}\sum_{i=1}^n(x_{i}-\mu_{x})(y_{i}-\mu_{y})
	\end{align}
$$
![](covariance.svg)

Here as mean is at origin (0,0),
- $(x_{i}-\mu_{x})(y_{i}-\mu_{y})$ will give positive value in 1st quadrant.
-  $(x_{i}-\mu_{x})(y_{i}-\mu_{y})$ will give negative value in 2nd quadrant.
-  $(x_{i}-\mu_{x})(y_{i}-\mu_{y})$ will give positive value in 3rd quadrant.
-  $(x_{i}-\mu_{x})(y_{i}-\mu_{y})$ will give negative value in 4th quadrant.
When averaging the values :
- If more datapoints are in 1st and 3rd quadrant positive values will dominate giving positive covariance value i.e., upward trend.
- If datapoints are equally distributed among the four quadrants, values will cancel each other out and either give positive or negative value but the magnitude is close to 0.
- If more datapoints are in 2nd and 4th quadrant negative values will dominate giving negative covariance value i.e. downward trend.

## PCA (Principle Component Analysis)

PCA helps us in finding the vector on which we will project the datapoints to decrease the dimension. 

Step 1 :  
First we center the datapoints.

![](center%20dp.svg)

Step 2 :  
Create the covariance matrix

![](covar%20mat.svg)

Step 3 :  
Find eigenvalues and eigen vectors of the covariance matrix. Matrix that are symmetric $C=C^T$ always give orthogonal eigen vector. As covariance matrix is always symmetric its eigenvectors always form orthogonal.

![](covar%20eigens.svg)

Now we have two eigenvectors which is also called Principle Components.

Step 4 :   
Choose the eigenvector whose eigen value is higher to project the datapoints. This gives maximum spreads. 

![](projection2.svg)

Here we turned a dataset with 2 features into 1.

If we had to decrease a larger table of 9 features to 2 features we take a set of 2 eigenvector and eigenvalues and do the same process. A dataset of shape $nX9$ will create a covariance matrix of shape $9X 9$ now if we create a matrix by taking eigen vectors of shape $9X 2$ so final result will have shape $nX 2$.
