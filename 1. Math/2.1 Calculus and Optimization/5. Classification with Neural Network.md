Neural network is  an architecture where multiple neuron interconnect with each other and data is shared between layers. A neuron is simply a mathematical model which involve :
1. Feed Forward
2. Loss Calculation
3. Back Propagation
4. Weights Updating.
Any model which involve this four basic steps can be considered an neural network,  

The classification model that we build in "Binary classification using Perceptron" also involved this four process :
1. Feed Forward : $z=w_{1}x_{1}+w_{2}x_{2}+b$.
2. Sigmoid Function : $\hat{y}=\sigma(z)$ 
3. Loss calculation : $\text{Log Loss, }L(y,\hat{y})=-y\ln(\hat{y})-(1-y)\ln(1-\hat{y})$
4. Back Propagation : calculating partial derivatives.
5. Weights Updating : using Gradient Descent for updating weights and bias
Hence the model can be considered a neural network involving a single neuron.

## Backpropagation

**backpropagation** is the core algorithm used to compute the **gradient of the loss function** with respect to the weights and biases in an artificial neural network. It applies the chain rule of calculus backwards from the output layer to the input layer to make training efficient
