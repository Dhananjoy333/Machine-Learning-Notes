By now we know for a function $f(x)$ the derivative at point x =2 is asking "if we nudge the value of x at that position (2) by a small amount what is the ratio of change in $f(x)$ to nudge value $dx$ which is $\frac{rise}{run}$ i.e., slope", whatever the ratio value approaches as $dx$ approaches 0 that is our derivative.

## Limits

![](limit%20hole.svg)

If we draw the graph of the function $\frac{(2+h)^3-(2)^3}{h}$ we get a parabola which is defined in all points except 0  as when h=0 function becomes $\frac{0}{0}$ which is not defined. Here limit basically helps us if we try to get close to 0 what happens ?. Here  as h approaches zero we get closer to 12, here it does not matter which side we are coming from if we are on left side and increase h by small amounts or we are on right side and decrease h by small amount both side approaches 12. 

What does approaching mean ?
As we know function is not defined at x=0 (input) . As we bring x closer and closer to 0 the output gets closer and closer to some value in this case it's 12.

## Epsilon Delta 

To formally define whether limit exists or not we take the help of epsilon ($\epsilon$) and delta ($\delta$) . Here epsilon is nothing but the range of vertical space and delta is the corresponding horizontal range.

![](limit-epsilon-delta.svg)

If limit exist for all $\epsilon$ value we will have $\delta$ value as shown above , but if limit does not exist

![](no-limit-epsilon-delta.svg)

Here no matter how small we make the $\delta$ value the corresponding output values is too big for $\epsilon$ value of range 2 to 1.

Hence Limit is used to define derivative and Epsilon-Delta is used to define limit. 

## L'Hôpital's rule

This is a systematic process to find the value of limit.  For example :

![](find%20limit.svg)

Here we can see the function is not defined at x = 1 and x = -1 . If we focus on x = -1 as x value approaches 1 , y value approaches some value, what is that value? . We might try to take x = 1.000001 or x =0.99999. But this would be approx. what is the precise value?

![](individual%20function.svg)

If we see the individual functions that make up the whole function both function is 0 at x = 1 and -1. Now if we find derivative of individual functions we can find for tiny nudge of x how the function change i.e., y value. Later we just combine to see the overall y value.

![](limit%20val.svg)

>[!Note]
>To find limit we differentiate numerator and denominator individually and put the value of x at which point we are trying to find the limit. If the denominator still has x we can apply L'Hopital again as long as replacing x = value result in $\frac{0}{0}$ or $\frac{\infty}{\infty}$
