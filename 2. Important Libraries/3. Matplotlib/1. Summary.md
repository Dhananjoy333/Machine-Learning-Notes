## Plotting

```
x = [2023, 2024, 2025, 2026]
y = [15, 25, 30, 20]
plt.plot(x,y)
plt.show()

x = np.array([2023, 2024, 2025, 2026])
y = np.array([15, 25, 30, 20])
plt.plot(x,y)
plt.show()
```

- Here it creates a simple line graph `.plot()` expects `(x-axis,y-axis)`. If we only pass one argument `plt.plot(arr)` it is taken as y-axis values and in x-axis a default values with 0.5 separation is provided like 0, 0.5, 1, 1.5, 2 ....
- Instead of python list using NumPy array is better as they are faster than python list.

## Plot Customization

### Markers

Markers are way to put some character at datapoints.

```
x = np.array([2023, 2024, 2025, 2026])
y = np.array([15, 25, 30, 20])
plt.plot(x,y, marker=".", marekrsize =20, markerfacecolor="red", markeredgecolor="black")
plt.show()

or

x = np.array([2023, 2024, 2025, 2026])
y = np.array([15, 25, 30, 20])
plt.plot(x,y, marker=".", ms =20, mfc="red", mec="black")
plt.show()

- markersize can be abbrebiated to ms
```

- There are many marker styles we can apply most common are : 
	- "." : simple dot.
	- "o" : circle.
	- "v" : triangle.
	- "\*" : asterisks .
- For color if we want custom color we can simply put hex value of the color. 

### Line styles

```
x = np.array([2023, 2024, 2025, 2026])
y = np.array([15, 25, 30, 20])
plt.plot(x,y, linestyle = "dotted", linewidth= 5, color = "#1c5bfc")
plt.show()
```

- We have many `linestyle` options like : "dotted", "dashed", "dash-dot", "None". None remove the line so we can only see datapoints, by default `linestyle` is simple line.

```
x = np.array([2023, 2024, 2025, 2026])
y1 = np.array([15, 25, 30, 20])
y2 = np.array([25, 18, 36, 13])
y3 = np.array([17, 27, 21, 19])

line_styles = dict(marker="o", ms =20, mfc="red",mec="black", linestyle = "solid", linewidth= 3)

plt.plot(x, y1, color = "#1c5bfc", **line_styles)
plt.plot(x, y2, color = "green",**line_styles)
plt.plot(x, y3, color= "orange",**line_styles)  

plt.show()
```

- If we have multiple lines and want same styles instead of re writing we can create a dictionary and simply reuse the styles.

### Grid lines

Grids help make plots easier to read by adding reference lines.

```
x = [1,2,3,4,5]
y = [5,10,15,20,25]

plt.grid() 

plt.plot(x,y)
plt.show()

- put grid lines we can control the grid lines by defined axis if we only want in one axis, by default it shows both lines.

plt.grid(axis="x") --> only verticle lines
plt.grid(axis="y") --> only horizontal lines
```

grid styles :

## Bar Charts

Bar chart compare categories of data by representing each category with a bar.

```
categories = np.array(["Grains", "Fruit", "Vegetables", "Proteins", "Dairy", "Sweets"])
values = np.array([4, 3, 2, 5, 3, 1])

plt.bar(categories, values, color = "cyan")
  
plt.title("Daily Consumption")
plt.xlabel("Food")
plt.ylabel("Quantity")

plt.show()

- If we want horizontal bar chart we can do :
  plt.barh(categories, values, color = "cyan")
```

All the styles application is similar to line chart.

## Pie Charts

Circular charts divided into slices to show percentages of the total. Good for visualizing distribution among categories.

```
categories = np.array(["Freshmen", "Sophomores", "Juniors", "Seniors"])
values = np.array([300, 250, 275, 225])

plt.pie(values, labels=categories)

plt.show()

- Addtional

categories = np.array(["Freshmen", "Sophomores", "Juniors", "Seniors"])
values = np.array([300, 250, 275, 225])
colors = ["red", "yellow", "blue", "green"] 

plt.pie(values, labels=categories, autopct="%1.1f%%", colors=colors, explode=[0,0,0,0.1], shadow=True, startangle=90) 

plt.title("College")

plt.show()

- autopct : adds percentages
- explode : take out and move the non zero slice a bit (0.1 here)
- shadow : add shadow
- startangle : rotate the pie chart
```

## Scatter Plot

Shows the relationship between two variables. Helps to identify a correlation (+, -, None). Ex : study hours vs test scores.

```
x = np.array([0, 1, 1, 2, 3, 4, 5, 6, 7, 7, 8]) #hours_studies
y = np.array([55, 60, 65, 62, 68, 70, 75, 78, 82, 85, 87]) # marks 

plt.scatter(x,y)  

plt.title("Test Scores")
plt.xlabel("Hours Studies")
plt.ylabel("Grade")

plt.show()
```

```
x1 = np.array([0, 1, 1, 2, 3, 4, 5, 6, 7, 7, 8]) #hours_studies
y1 = np.array([55, 60, 65, 62, 68, 70, 75, 78, 82, 85, 87]) # marks

x2 = np.array([0, 1, 2, 2, 3, 3, 5, 6, 7, 8, 8]) #hours_studies
y2 = np.array([50, 58, 67, 71, 63, 73, 75, 79, 92, 80, 97]) # marks

plt.scatter(x1,y1, color= "skyblue", alpha= 0.5, s = 100, label = "Class A")
plt.scatter(x2,y2, color= "red", alpha= 0.5, s = 100, label="Class B")

plt.title("Test Scores")
plt.xlabel("Hours Studies")
plt.ylabel("Grade")

plt.legend()
plt.show()

- alpha controls tranparency.
- legend() shows the label with color on top.
```

## Histograms

A visual representation of the distribution of quantitative data. They group values into bins (intervals) and count how many fall in each range.

```
scores = np.random.normal(loc= 80, scale= 10, size= 100)
scores = np.clip(scores, 0, 100)

plt.hist(scores)

plt.show()

- we use numpy to generate random marks with normal distribution with center(loc) at 80 (values will cluster around 80), standard deviation(scale) of 10(most values will be at distance of 10 from 80), size is 100
- clip helps in setting range all scores below 0 will be 0 and all scores above 100 will be 100.
```

```
scores = np.random.normal(loc= 80, scale= 10, size= 100)
scores = np.clip(scores, 0, 100)

plt.hist(scores, bins= 10, color= "lightgreen", edgecolor= "black")

plt.title("Exam scores")
plt.xlabel("Score")
plt.ylabel("Number of students")

plt.show()
```

## Subplots

Figure : Entire canvas.
Ax : A single plot (subplot).
Subplot is basically showing multiple graphs in single canvas.

```
figure, axes = plt.subplots(2, 2)

plt.show()

- This creates 4 subplots here subplots(row,col)
```

```
#subplots

x = np.array([1,2,3,4,5])

figure, axes = plt.subplots(2, 2)

axes[0,0].plot(x,x*2, color= "red")
axes[0,0].set_title("x*2")

axes[0,1].plot(x, x**2, color="blue")
axes[0,1].set_title("x**2") 

axes[1,0].plot(x, x**3, color= "green")
axes[1,0].set_title("x**3")

axes[1,1].plot(x, x**4, color= "yellow")
axes[1,1].set_title("x**4") 

plt.tight_layout()

plt.show()

- Instead of plot we can also use bar, pie, histogram as we wish.
```

## Pandas + Matplotlib

```
import pandas as pd

df = pd.read_csv("./datasets/one_piece_100_plus.csv")

df = df.drop_duplicates()

faction_count = df["faction"].value_counts(ascending=True)

plt.barh(faction_count.index, faction_count.values, color = "cyan", edgecolor= "black")

plt.title("Total character in each faction")
plt.xlabel("Count",color = "red")
plt.ylabel("Faction", color = "red") 

plt.tight_layout()

plt.show()

- data cleaning with drop duplicates
- .value_counts() return counts by grouping values.
```
