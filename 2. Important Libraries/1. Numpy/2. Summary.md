### 1.1 - System of Linear Equations

A **system of linear equations** (or **linear system**) is a collection of one or more linear equations involving the same variables. For example:

$$
	\begin{align}
	-x_{1} + 3x_{2}&=7 \\
	3x_{1} + 2x_{2} &=1
	\end{align}
$$

is a system of two equations with two unknown variables $x_{1}$ and $x_{2}$. **To solve** a system of linear equations means to find values for the variables $x_{1}$ and $x_{2}$ such that all of its equations are simultaneously satisfied.

A linear system is **singular** if it has no unique solution, and otherwise, it is said to be **non-singular**.

### 1.2 - System of Linear Equations as Matrices

In the lecture, you saw that we represented linear systems of equations as matrices. The system (1) represented as a matrix is as follows:

$$
	\begin{bmatrix}
	-1&3&7 \\
	3&2&1
	\end{bmatrix}
$$

Each row represents an equation in the system. The first column represents the coefficients of 𝑥1 in the system, the second column represents the coefficients of 𝑥2, and the third column represents the constant values on the right side of the equals signs in the equations.

We could further choose to represent the coefficients of the system (1) as its own matrix 𝐴 as follows:

$$
	\begin{bmatrix}
	-1&3 \\
	3&2
	\end{bmatrix}
$$

and the outputs of the system as a vector 𝑏 like this:

$$
	\begin{bmatrix}
	7 \\
	1
	\end{bmatrix}
$$

We show the matrix 𝐴 and vector 𝑏 in `NumPy` below:

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))

b = np.array([7, 1], dtype=np.dtype(float))

print("Matrix A:")
print(A)
print("\nArray b:")
print(b)
```

Now we know ,
$$
	\begin{align}
	Ax&=b \\
	x&=A^{-1}b \\
	where, \\
	A&=\text{matrix} \\
	A^{-1}&=\text{inverse matrix} \\
	x &= \text{unknown vector} \\
	b &= \text{solution vector} 
	\end{align}
$$
### Linear Algebra operations in NumPy

In NumPy operations such as matrix multiplication, inverse matrix, matrix addition etc. are done by an in-built submodule used with `np.linalg`.

- `np.linalg.solve(A,b)` : find the unknown for matrix A and output vector b.

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))
b = np.array([7, 1], dtype=np.dtype(float))
solve = np.linalg.solve(A,b)
print(f'solution: \n {solve}')

# output : solution: [-1. 2.]
```

- `np.linalg.inv(A)` : Returns inverse of matrix. We can use this to solve the previous problem but it is recommended to use `np.solve()` for solving equations.

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))  
b = np.array([7, 1], dtype=np.dtype(float))
inverse = np.linalg.inv(A)
sol = inverse @ b
print(f'solution: \n {sol}')

# output : solution: [-1. 2.]
```

- `np.det(A)` : Returns the determinant of matrix A.

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))
det = np.linalg.det(A)
print(det)

# output : -11.000000000000002, det should be -11 but when python stores values in binary integers get small error which is negligible we can also round(det) for proprt answer.
```

- `np.linalg.matrix_rank(A)` : Returns rank of matrix A.

```python
A = np.array([

    ], dtype=np.dtype(float))
```

- `np.linalg.eig(A)` : Returns an array with two values first is eigenvalue and second eigen vectors.

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))
eig = np.linalg.eig(A)
print(eig)

# output : EigResult(eigenvalues=array([-2.85410197, 3.85410197]), eigenvectors=array([[-0.85065081, -0.52573111], [ 0.52573111, -0.85065081]]))

# deconstruct for better readbility
eigenvalues, eigenvectors = np.linalg.eig(A)
print(eigenvalues)
```

- `np.linalg.eigh(A)` : computes the eigenvalues and eigenvectors of a **complex Hermitian** or real symmetric matrix. Similar to `np.linalg.eig(A)` 
	-  **Guaranteed Sorted Output**: The eigenvalues are always returned in **ascending order**.
	- **Faster Execution**: It utilizes optimized LAPACK drivers (`_syevd`/`_heevd`) tailored for symmetric geometry, making it significantly faster than the general `np.linalg.eig` function.
	- **Memory Assumption**: It does not check if the matrix is perfectly symmetric. It reads only the lower triangular portion by default and assumes the rest matches.

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))
eigh = np.linalg.eigh(A)
print(eig)

# output : EigResult(eigenvalues=array([-2.85410197, 3.85410197]), eigenvectors=array([[-0.85065081, -0.52573111], [ 0.52573111, -0.85065081]]))
```

- `np.linalg.svd(A)` : compute singular vector decomposition.

```python
A = np.array([
        [-1, 3],
        [3, 2]
    ], dtype=np.dtype(float))
svd = np.linalg.svd(A)
print(svd)

# output : SVDResult(U=array([[ 0.52573111, 0.85065081], [ 0.85065081, -0.52573111]]), S=array([3.85410197, 2.85410197]), Vh=array([[ 0.52573111, 0.85065081], [-0.85065081, 0.52573111]]))

# for better readability
U, S, Vt = np.linalg.svd(A)
```

- `np.mat_mul(A,b)` , `@`, `np.dot(A,b)` : All three does matrix multiplication

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])

B = np.array([[5, 6],
              [7, 8]])

print(A @ B)
print(np.matmul(A, B))
print(np.dot(A, B))

# same output for all three : [[19 22] [43 50]]
```

- `*` , `np.multiply(A,B)`: does element wise multiplication.

```python
A = np.array([[1, 2],
              [3, 4]])

B = np.array([[5, 6],
              [7, 8]])
              
print(A*B)
print(np.multiply(A,B))

# output : [[5 12] [21 32]]
```
