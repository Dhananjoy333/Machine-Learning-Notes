Seaborn is  a data visualization library build on top of matplotlib. Seaborn make assumptions for what we want making code more readable and smaller unlike matplotlib where we need to define everything manually. Also seaborn has built-in datasets that we can use to learn which matplotlib does not.

Advantages :
- No Preprocess : In matplotlib we would need to extract the required columns from DataFrame and then pass it to x and y values. But in seaborn we don't need to do that we can directly pass column name and seaborn automatically take those values.

```
x = crash_df["speeding"]
y = crash_df["alcohol"]

plt.scatter(x, y)

in Seaborn

sns.scatterplot(
    data=crash_df,
    x="speeding",
    y="alcohol"
)
```

- Automatic grouping : In matplotlib to group data and show its graph we need to use pandas for group, get the data, then plot. But in seaborn, it can group automatically, no need of pandas.

```
grouped = df.groupby(["faction", "gender"])["bounty"].mean()
grouped.unstack().plot(kind="bar")
plt.show()

in seaborn

sns.barplot(
    data=df,
    x="faction",
    y="bounty",
    hue="gender"
)
```
