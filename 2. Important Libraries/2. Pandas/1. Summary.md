Pandas is a python library built on top of NumPy. it is widely used in Data analysis, data science and machine learning. The name Pandas comes from 'Panel - Data'. 

Steps to working with pandas
- Data handling and cleaning : will use methods like : `dropna()`, `fillna()`,`drop-duplicates()`.
- Data manipulation : `groupby()`, `merge()`.
- Data analysis and exploration : finding mean, median, highest, lowest etc., values from the dataset based on requirement .
- Handling different types of files : Our data will be in the form of `excel`, `csv`, `json`, `sql` etc., form that needs to be fetched to use in python.
- Converting data : Data that was fetched needs to be converted to pandas understandable format which is called frames or series. If data is converted to :
	- 1D ---> Series
	- 2D ---> Data frames
- Using data in NumPy, Matplotlib, Seaborn etc., this is called integration

We can think of Pandas as a mini SQL. Just like SQL where we manipulation, change, query data in Pandas we do the same. Unlike SQL that require new environment and query language Pandas is built-in on python but Pandas does not store data like SQL. Also Pandas run query in in-memory RAM which makes it really fast.

## Series

A pandas 1-D labeled array that can hold any data type. Its like a single column in a spreadsheet or a vector.

```
data = [100, 102, 104]
series = pd.Series(data)
print(series)

- output : 
  0 100 
  1 102 
  2 104 
  dtype: int64
- Here Series is not a function. It is a constructor function, so it creates object.
- Here type of data stored is 64bit integer

data = [100.1, 102, 104]
- output : 
  0 100 
  1 102 
  2 104 
  dtype: float64
  
data = ["Cat", "Dog", "Pig"]
- output : 
  0 Cat 
  1 Dog 
  2 Pig 
  dtype: str

data = ["Cat", 123, 9.8]
- output : 
  0 Cat 
  1 123 
  2 9.8 
  dtype: object
```

By default, indexes of items are 0,1,2... but we can set custom indexed

```
data = [100, 123, 333]
series = pd.Series(data, index= ["first", "second", "third"])
print(series)

- output : 
  first 100 
  second 123 
  third 333 
  dtype: int64
- we can also set another array as index. If the index length doesnot match the array length, it give error.
```

### Searching values

```
data = [100, 123, 333]
series = pd.Series(data, index= ["first", "second", "third"])
print(series["first"])

- We can search like this but is not recommended as if we change index to numbers
series = pd.Series(data, index= [1, 2, 3])
- here if we do 
print(series[1])
- Its confusing whether we want 100(our index) or 123(0-based default index). Here te output will be from our index i.e., 100 
```

searching in pandas is done with :
- `.loc`
- `.iloc`
### .loc (location) 

we specifically want to search by label

```
data = [100, 123, 333]
series = pd.Series(data, index= ["first", "second", "third"])
print(series.loc["first"])

- output : 100
```

### .iloc (locate by integer)

```
data = [100, 123, 333]
series = pd.Series(data, index= ["first", "second", "third"])
print(series.iloc[0])

- output : 100
- Even though we have changed the index the 0-based default index stays
```

### Filtering

```
data = [100, 123, 333, 500, 111, 300]
series = pd.Series(data, index= ["first", "second", "third", "fourth", "fifth", "sixth"])
print(series[series < 200])

- output :
  first 100 
  second 123 
  fifth 111 
  dtype: int64
- simply write the condition inside [].
```

### Using Dictionary instead of list

If we use dictionary instead of list we don't have to give index as key becomes the index.

```
calories = {"Day 1" : 1750, "Day 2" : 2100, "Day 3" : 1700, "Day 4" : 1900}
series = pd.Series(calories)
print(series.loc['Day 3'])

- output : 1700

series.loc["Day 3"] += 1200
- updates the value.
  
print(series[series > 1800])
- filter and return the matching condition.
```

```
print(df.loc[0])
or

we can also slice with the help of iloc

```
print(df.iloc[:11:2])

print(df.iloc[:11, 0:2])

- .iloc[rows, cols] rows start from first, go till 11(exclusive). For column take first 2 column i.e, 0,1

### Aggregate

Reduces a set of values into single summary value. Used to summarize and analyze data. Often used with `groupby()` function.

```
df = pd.read_csv("./datasets/one_piece_100_plus.csv")
print(df.mean(numeric_only=True))

- For entire dataset any column that is numeric find it mean().
- Similarly we can do : sum(), min(), max(), count()

print(df["bounty"].mean())

- Here we are finding mean() for a single column.
```

### `.groupby()`

`.groupby()` function is used to group data based on something that is common to multiple entries.

```
group = df.groupby("faction")
print(group["bounty"].mean())

- groupby() return a GroupBy object so print(group) simply shows the object address.
- but we can use group to perform some computaion.
- Here we are grouping rows by faction than finding the bounty mean of each faction. 
```

### Data Cleaning

Data cleaning is the process of fixing/removing incomplete, incorrect, or irrelevant data. 75% of work done with pandas is data cleaning.

```
# Drop irrelevant cols
df = df.drop(columns=["gender"])
print(df)

#handle missing data
df = df.dropna(subset=["fruit_type"])
print(df)

- Drops Not Available (na) values in column "fruit_type".
  
# replace value
df = df.fillna({"devil_fruit": "Unknown"})
print(df)

- instead of removing we replace the na values in "devil_fruit" column to "Unknown"
  
#replace value
df["fruit_type"] = df["fruit_type"].replace({"Paramecia": "PARAMECIA"})
print(df)
- update column "fruit_type" as inside column "fruit_type" replace all "Paramecia" to "PARAMECIA"
  
# standardize text(turn to lower case)
df["name"] = df["name"].str.lower()
print(df)

- Update column "name", all name to lower(). 
  
#remove duplicate
df = df.drop_duplicates()
print(df)

- Remove all duplicate values. Pandas consider two entries to be duplicate if all column values are equal.
```
