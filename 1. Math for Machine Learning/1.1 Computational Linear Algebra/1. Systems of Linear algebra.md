In math we already know and solved multiple question involving linear equation of form :
$$
	\begin{align}
	y&=mx +c \\
	where, \\
	y&=output \\
	x&=input \\
	m&=slope \\
	c&=intercept
	\end{align}
$$
When we view graphically we see a straight line where $m$ controls slope and $c$ controls the point at which line intersect y-axis. For ex : for $y=2x+3$

Given two linear equation of two variable we can easily solve it and find the values of y and x

Here given the values of $m$ and $c$ we find values of $y$ and $x$.

## Linear Regression

Linear regression is a supervised machine learning model designed to predict values which works on linear algebra. In a simple linear eq. $y=mx+c$ , the values of $m$ and $c$ set up a relationship between $input:x$ and $output:y$. Such that if we know the values of $m$ and $c$ we can easily find the value of $y$ for any given $x$.

Unlike previous question where we find values of $y$ and $x$ with given $m$ and $c$ . In Linear regression, we already have values of $output:y$ and $input:x$ and try to find values of $m$ and $c$.
$$
	\begin{align}
	y&=wx+b \\
	where, \\
	y&=output \\
	x&=input \\
	w&=weight \\
	b&=bias
	\end{align}
$$
For example 

![](assets/1.%20System%20of%20Linear%20algebra/simple_LR.png)

- Here we have a data of hours studied and marks scored we plot it in graph and try to find the values of weight $w$ and bias $b$ which try to pass through all the points with least error. 
- Now once we find weight and bias we can approximate how much marks the student will get given the no. of hours studied.
- Here we have one single input (hours studied), which is called Input Feature.
In real machine learning model we have multiple features so the eq. formed is multivariant linear equation.

![](assets/1.%20System%20of%20Linear%20algebra/multi_linear_eq.png)

>[!Note]
>In general, equation formed in linear regression is represented as :
>$$
>	\begin{align}
>	w_{1}x_{1}^m + w_{2}x_{2}^m + w_{3}x_{3}^m + \dots+w_{n}x_{n}^m=y^m
>	\end{align}
>$$
>
![](assets/1.%20System%20of%20Linear%20algebra/LR_eq.png)
>Computers does not understand linear eq. so we represent the linear eq. in form of matrix and vector and solve it
> 
![](assets/1.%20System%20of%20Linear%20algebra/LR_mat.png)

The values of input and output does not form perfect linear equations. If it was we could have solved it with pen and paper and fount the value of weight and bias. Because no perfect line passes through all input and output point we instead use iterative approach to approximate a line that comes closest to all input and output points.
