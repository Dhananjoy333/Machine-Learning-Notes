## Type 2 error ($\beta$)

![](../assets/Hypothesis%20testing_2/POT.svg)

Previously we have extensively seen ways to reduce Type 1 error. 
- We have defined significance level ($\alpha$) which is a value of risk we are willing to accept Type 1 error.
- We calculated the heights sample mean of students that are 18 y/o and compared it to older population mean and asked 3 question or did 3 test :
	- Left Tailed Test 
	- Right tailed Test
	- Two Tailed Test
- In all test we have calculated the minimum value of mean, above/below which we can reject null hypothesis which was the critical value.
Here we will see more about Type 2 error i.e., for right tailed test, we have concluded that height have not increased over the years but in reality it has which can be interpreted as we did not reject null hypothesis (height has not changed) when we should have. Or the alternate hypothesis is true but we failed to reject null hypothesis. We know alternate hypothesis will only be true if we reject null hypothesis, failing to reject null hypothesis mean we stay in null hypothesis resulting in Type 2 error

![](../assets/Hypothesis%20testing_2/POT_1.svg)

If we calculated the sample mean to be 70, now imagining that alternate hypothesis is true (average height has increased), our new population mean becomes 70. We know if $H_{o}$ was true we do not reject values below critical value $k=68.26$. Hence if $H_{1}$ is true, region where we do not reject $H_{o}$ will cause error (Type 2 error).

![](../assets/Hypothesis%20testing_2/POT_2.jpg)

The probability of Type 2 error is represented by $\beta$.
## Power of Test

Power of test is the probability of correctly determining that height has increased or rejecting null hypothesis $H_{o}$. Since $\beta$ gives the probability of not rejecting $H_{o}$ , power of test is simply the compliment of $\beta$ i.e., $1-\beta$.
