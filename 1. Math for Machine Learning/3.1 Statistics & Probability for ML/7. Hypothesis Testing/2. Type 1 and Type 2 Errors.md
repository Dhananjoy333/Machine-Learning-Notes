## Significance Level

Because Type 1 is more detrimental than Type 2, we need to have some accepted probability we are willing to accept Type 1 error.

A significance level (denoted as **α or alpha**) is the risk level you choose before a test. It shows the chance of saying a result is real when it is only random. People often set this value to **5% (0.05)** or **1% (0.01)**.

![](../assets/Hypothesis%20testing/type_2.svg)

Here,
- If $\alpha$ is 0, all email will always be considered a ham, increasing the Type 2 error (spam being categorized as ham).
- If $\alpha$ is 1, all email will always be considered a spam, increasing the Type 1 error (ham being categorized as spam).
- As Type 1 error is more detrimental than Type 2 error we try to keep $\alpha$ as low as possible i.e., willing to risk ham being labelled as spam.

## Right Tailed, Left Tailed and Two Tailed Test

We find the average height of a 18 y/o student in US, to do that we take sample of 10 students and found that $\bar{x}=68.442$. For taking the sample the data need to be reliable, a reliable data need to be representative of the 18 y/o student (should not be taken in such a way that all 10 student are basketball player as it inserts bias basketball players are usually taller), the data need to be randomized and the sample size need to be decent.

![](../assets/Hypothesis%20testing/tailed.svg)

Now if we ask the question : Has the average height of 18 y/o student in US increased ? Looking at the sample mean we might assume it has increased but is it really true. Hence we do the hypothesis test.  
We take a null hypothesis $H_{o}$ (nothing changed) and alternate hypothesis $H_{a}$ (height has increased).   
We can see above we are comparing the sample test mean to population mean.

![](../assets/Hypothesis%20testing/tailed_1.svg)

Now to test the hypothesis we have 3 options, Or we have 3 questions
1. **Right Tailed Test** : Has the height increased over the year? i.e., the alternate hypothesis is greater than null hypothesis.
2. **Left Tailed Test** : Has the height decreased over the year? i.e., the alternate hypothesis is lesser than null hypothesis.
3. **Two Tailed Test** : Has the height changed over the year? (could have increased or decreased) i.e., the alternate hypothesis is not equal to null hypothesis.
