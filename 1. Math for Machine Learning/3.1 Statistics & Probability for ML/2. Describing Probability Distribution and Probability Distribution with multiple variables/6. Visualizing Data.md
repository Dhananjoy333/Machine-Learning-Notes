## Quantile (IQR)

Quantiles is basically a way to separate certain percentage of data in the dataset. 
If we have a dataset show the amount of money spent on advertisement, 

![](../assets/visualizing%20data/dataset.svg)

first to find median we rearrange the dataset in ascending order.

![](../assets/visualizing%20data/1st%20and%202nd%20quantile.svg)

- $1st$ Quantile : If dataset is divided in $25\%-75\%$, it is called first quantile and the value is the dataset that separate the dataset in the given percentages.
-  $2nd$ Quantile : If dataset is divided in $50\%-50\%$, it is called first quantile and the value is the dataset that separate the dataset in the given percentages.
-  $3rd$ Quantile : If dataset is divided in $75\%-25\%$, it is called first quantile and the value is the dataset that separate the dataset in the given percentages.
We can divide the dataset in $n$ number of quantile as we wish but this 3 are the most common and useful divisions

![](../assets/visualizing%20data/kth%20quantile.svg)

After finding the $1st,2nd,3rd$ quantiles we can calculate the IQR by

$$
	IQR = Q_{3}-Q_{1}
$$
IQR help us in finding the outlier in dataset.

## Kernel Density Estimation (KDE)

The above dataset that we used is a continuous distribution, and we have dealt with continuous distribution as curves in graph. KDE help us in representing the data in continuous curves

![](../assets/visualizing%20data/steps%20to%20KDE.svg)

- Step 1 : Initially we draw a line for each point on dataset. 
- Step 2 : For each line we draw a small Gaussian curve. The height and width (fatness) of the curve is determined by the ***bandwidth***. Here each normal distribution has inner area as 1.
- Step 3 : Since each inner area is 1 when we sum up all the area then lets say we have $n$ dataset then the total area becomes $n$ $units^2$ . But in probability distribution the total inner area must be 1. Hence we divide the number of dataset $n$ to the final summed area to keep the total area as 1.
Finally we get our final continuous curve 

![](../assets/visualizing%20data/KDE.svg)

KDE helps us in visualizing the distribution of the dataset and understand at which parts the distribution is more concentrated.

## QQ Plot

QQ plot stands for quantile quantile plots. Usually in most machine learning data, we go by assumption that the data follow a normal distribution. But before training with the data, it is better to understand how much the data follow normal distribution. To see this we can simply plot the data in a KDE or histogram and see the graph pattern. But the more accurate way is to use QQ plot.

![](../assets/visualizing%20data/qq%20plot.svg)
