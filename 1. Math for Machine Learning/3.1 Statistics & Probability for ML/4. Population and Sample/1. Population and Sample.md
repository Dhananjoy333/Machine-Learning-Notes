The population is represented by $N$ and sample is represented by $n$. Here sample can be any value from $1-9999$ .

- In a population, sample should always be picked randomly. For example if we want to calculate the average height of a population. When taking a sample from the population, people should be picked randomly instead of arranging by height wise and selecting from only one side

![](../assets/Population%20and%20sample/sample%20selection.svg)

- If we select multiple sample set, we should not discard the previously selected sample set as this makes next selection of sample set dependent on previous sample set. Sample selection must be independent.

![](../assets/Population%20and%20sample/sample%20selection_2.svg)
