Covariance help us in understand the trend by analyzing how Y changes as X increase but does not give us information about how much closely X and Y are correlation to each other.

Correlation measures how consistently two variables follow a linear pattern together. It is measured from -1 to 1. 
- If we plot the points of $(x,y)$ on graph and get a perfect line i.e, points follow a linear equation and the points has positive slope than the correlation is exactly 1. If the datapoints create an upward trend but the points are not perfectly aligned i.e, some points are scattered then based on how much the points scatter, correlation is between $0\to1$.
- Similarly for a datapoints that form a perfect line and has negative slope, correlation is exactly -1. And if it has some points scattering the values range from $-1\to0$ .
- If no trend is observed correlation value is close to 0.
