We have seen for 1 variable, the Normal/Gaussian distribution is a symmetric bell shaped curved.

![](../assets/Gaussian%20Dist/gaussian%20curve%20for%201%20var.svg)

For multivariant, we can plot the datapoints on a scatter plot and see the distribution w.r.t $x$ or $y$ and we see that both forms a gaussian curve. 

Assuming the 2 variables as independent, combining the curve give us a symmetric 3D bell.

![](../assets/Gaussian%20Dist/gaussian%20curve%20of%202%20var.svg)

In below graphs we can see that for independent variables the bell is symmetric whereas for dependent variables the bell is a bit skewed.

![](../assets/Gaussian%20Dist/2%20var%20gaussian%20dist.svg)
