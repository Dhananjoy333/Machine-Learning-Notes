In all previous cases we have always know the standard deviation of the population but in reality this is not the case, we won't always know the standard deviation of the population.  
In this case we can simply replace the population standard deviation with sample standard deviation, doing so will cause the distribution to no longer be a normal distribution instead it is called Student's t-distribution

![](../assets/Confidence%20Intervals/t-dist.svg)

Student's t-distribution looking similar to normal distribution but has fatter tails.  
Now that the distribution is no longer normal distribution another problem which occur is critical value $z$ is dependent on normal distribution, simply using critical value of normal distribution will cause error

![](../assets/Confidence%20Intervals/t-dist_1.svg)

Unlike normal distribution the t-distribution changes based on "***degree of freedom***"
