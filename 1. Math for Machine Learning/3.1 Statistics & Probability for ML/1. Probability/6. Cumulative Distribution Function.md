In Probability Density Function we had to calculate the area under the curve to find the probability for certain range. CDF is just a different version of PDF where we show the probability from interval 0 upto point $t$.

![](../assets/cont.%20prob/CDF.svg)

CDF is found simply by taking the addition of previous probability upto that point.

![](../assets/cont.%20prob/CDF%202.svg)

Both the curves give us the same info the only difference is to find the probability in PDF we need to find the area and in CDF we simply have to find the height. Also, CDF has a hard limit on left and right side as at start no area will be added, CDF will always start from 0 and towards the right most side as the max probability when summed up need to be 1, the CDF curve will have height 1.

![](../assets/cont.%20prob/pdf%20vs%20cdf.svg)
