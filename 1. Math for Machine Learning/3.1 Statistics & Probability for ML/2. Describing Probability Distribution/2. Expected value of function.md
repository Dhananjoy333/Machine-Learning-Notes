we know an expected value of random variable $X$ is calculated as 

$$
	\mathbb{E}[X=x]=\sum_{x}xP_{X}(x)
$$
if random variable is a function of $g(X)$ , expected value is simply calculated as 

$$
	\mathbb{E}[g(X)]=\sum_{x}g(X)P_{X}(x)
$$

Example - 1 : If we roll a die and win square of whatever value comes up :

![](../assets/expected%20val%20of%20function/expected%20value%20of%20func.svg)

here the win condition is a function $X^2$ .

$$
	\mathbb{E}[X=x^2]=\sum_{x}x^2P_{X}(x)
$$

Example - 2 : If we roll a die and win double of whatever appears. But we need to pay $5 to start the game :

![](../assets/expected%20val%20of%20function/expected%20val%20of%20func_2.svg)

Here 

$$
	\mathbb{E}[aX+b]=a\mathbb{E}[X]+b
$$

This suggest that Expectation is a linear operator.

A linear operator is a special type of mathematical function that maps elements from one vector space to another while preserving vector addition and scalar multiplication. It follows the rule T(u + v) = T(u) + T(v) and T(c v) = c T(v) for any vectors and numbers.

Some common examples of linear operators are : derivative $\frac{\delta y}{\delta x}$, integral $\int$ ,matrices etc.
