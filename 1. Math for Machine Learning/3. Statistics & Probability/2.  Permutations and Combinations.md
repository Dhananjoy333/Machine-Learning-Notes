## Factorial

A factorial is simply a mathematical operation that multiplies a non-negative integer by every positive integer less than it.

$n! =n*(n-1)*(n-2)*(n-3)*\dots*1$    here n is a non-negative integer

Properties of factorial :
- $0! = 1$
- $n! =n*(n-1)!$

Q. Given a word 'SUN'. How many words can be formed by rearranging letters?

Ans. All the words after rearranging will have 3 letters,
               ___  ___  ___
	Idea :
		We can either choose to select or not select letters of 'SUN' one by one to be placed in the empty positions.
		![](assets/1.%20Permutation%20and%20Combinations/rearrange-SUN.svg)
		
		1. The word 'SUN' has 3 letters for first position we have 3 choices.
		2. Once first is chosen, for second place we have 2 choices each. So, by multiplication rule : 3*2
		3. For third place we have 1 choice for each second choice. Again multiplication rule : 3*2*1

>[!Note]
>Here its basically $3! =3*2*1$. Therefore the no. of ways to rearranging n unique number of letters/numbers is $n!$.

## Permutation

- Permutation means ordered selection (Arrangement). 
- A **permutation** is a mathematical calculation of the number of ways a set of items can be arranged or ordered, where the sequence or position of the items is strictly important.

Q. Given word 'PENCIL'. How many 3 letter words can be formed ?

Ans: Here during selection order of letters matter as $'PEN'\neq 'EPN'$. Hence it is permutation problem.

![](assets/1.%20Permutation%20and%20Combinations/3choice_of_PENCIL.svg)

>[!Formula]
>no. of arrangement of n unique objects taken k at a time is Permutation.
>$$
>	{}^{n}P_{k} = \frac{n!}{(n-k)!}
>$$

## Combination

- Combination means unordered selection.
- A mathematical combination is a way of selecting items from a larger set where the order of selection does not matter.

Q. I need to select 3 books out of 5 books for reading. In how many ways can I select the book?

Ans: Here I only need to select 3 book, does not matter which books i select. Hence order does not matter. So it is a Combination problem.

![](assets/1.%20Permutation%20and%20Combinations/combination.svg)

>[!Formula]
>no. of ways to select k objects from n no. of objects where order does not matter is Combination. 
>No two selection has all objects as same. Each selection has at least one unique object.
>$$
>	{}^{n}C_{k} = \frac{n!}{(n-k)!.k!}
>$$

## Relationship between Permutation and Combination

$$
	{}^{n}P_{k}={}^{n}C_{k}.k!
$$
## Questions in Permutation

Q. For the word 'CINEMA'

1. No. of total 6 letter words = $6!$.

2. Always begin with C = $1*5!$ (first place is fixed with C).

3. Start with C and ends with A = $1*4!*1$.

4. C and A should be at edges :
	- Case 1 : C at start A at end = $1*4!*1=4!$
	- Case 2 : C at end A at start = $1*4!*1=4!$
	- S0, total cases : $2*4!$

5. C and I should always be together :
	- We can take C and I as one object so total letters are {CI, N, E, M, A} =$5!$
	- C and I can also be interchanged = $2!$
	- Total cases = $5!*2!$

6. C, I and N should always be together :
	- Same as previous treat C, I and N as one object so total letters area {CIN, E, M, A} = $4!$
	- C, I and N can also be interchanged = $3!$
	- Total cases = $4!*3!$
