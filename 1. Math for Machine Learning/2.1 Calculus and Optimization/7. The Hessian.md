## Concavity

In equations with 1 variable we can simply find second derivative and know if the extrema is maxima or minima by :
- If $f''(x)>0$ , local minima.
- If $f''(x)<0$ , local maxima.
- If $f''(x)=0$ , inconclusive.
But when no. of variables increases we get hessian matrix. To see whether the extrema is maxima or minima using hessian matrix, we simply need to find the eigen values of the hessian matrix.
- If all eigen values > 0 , local minima.
- If all eigen values < 0 , local maxima.
- If some eigen values are positive and some are negative, inconclusive.
- If any one or all of eigen values are 0, inconclusive.
